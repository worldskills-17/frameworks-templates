# NestJS Template

Bare NestJS skeleton for WorldSkills UK competitions. TypeScript, Express adapter, listens on port 80.

## Versions

- NestJS 12 (`@nestjs/core`, `@nestjs/common`, `@nestjs/platform-express`) on Express 5
- TypeScript 6 (the Nest 12 CLI does not support TypeScript 7 yet)
- Node.js: Docker image `node:24`; Nest 12 needs Node 20.19+ / 22.12+ (the Nest CLI needs 22.22.3+, 24.15+ or 26+)

The project is CommonJS (`module: nodenext` in `tsconfig.json`, no `"type": "module"` in `package.json`), as generated by `nest new`.

## Local development

```bash
npm install
npm run start:dev
```

## Production build

```bash
npm run build
node dist/main.js
```

## Container build (CI)

Triggered automatically on push to `main` via Gitea Actions. Image is published to the local Gitea registry and Watchtower deploys it within 30 seconds.

## Endpoints

- `GET /` — landing HTML
- `GET /test` — JSON health check
